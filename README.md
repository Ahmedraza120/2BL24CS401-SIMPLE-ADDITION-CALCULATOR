## Problem Statement
This is a Simple Addition Calculator built using Java Servlets. The user enters two numbers into an HTML form, and the Servlet processes these inputs to calculate their sum, displaying the result as a full mathematical expression (e.g., 12 + 35 = 47).

## Technologies Used
- Java 21 (Jakarta Servlets 6.0)
- HTML5 & CSS3
- Apache Tomcat 10.1
- Eclipse IDE

## How to Run This Project
1. Clone this repository or download the ZIP.
2. Import the project into Eclipse as a Dynamic Web Project.
3. Ensure Apache Tomcat 10.1 is configured as the target runtime.
4. Right-click the project → **Run As** → **Run on Server**.
5. Open your browser and go to: `http://localhost:8080/Simple_Addition_Calculator/index.html`
